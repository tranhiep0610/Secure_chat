# Secure Chat - Backend

Backend của hệ thống Secure Chat, xây dựng bằng Node.js, Express và MongoDB.

## 1. Công nghệ sử dụng

- Node.js
- Express.js
- MongoDB
- Mongoose
- bcryptjs
- express-session
- cookie-parser
- express-rate-limit
- Socket.IO
